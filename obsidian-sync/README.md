# NotebookLM → Obsidian 自動保存ツール

議事録や調査メモを、**手作業なしで Obsidian の保管庫（アレクサンドリア図書館）に
Markdown ファイルとして貯めていく**ためのツールです。

AI やプログラムに詳しくない方でも進められるよう、順番に書いています。
上から順にやってみてください。

---

## 0. はじめに知っておいてほしいこと

### NotebookLM の中身は、外から自動で取り出せません

NotebookLM には、**個人向けの「API」（プログラムから中身を読み取る窓口）が用意されていません。**
これは Google がまだ公開していないためで、こちらの工夫ではどうにもなりません。
（法人向けの NotebookLM Enterprise だけが API に対応しています）

そのため「NotebookLM に保存されるたびに、自動で見に行く」という仕組みは作れません。

### かわりに「入口」と「出口」を押さえます

```
                    ┌──→ NotebookLM（今まで通り。AIとの対話用）
   元のファイル ────┤
   （文字起こし等） └──→ 取り込みBOX ──→ 自動変換 ──→ Obsidian（保管用）
```

元のファイルを **NotebookLM と Obsidian の両方に配る** 形にします。
NotebookLM の使い方は今までと何も変わりません。

このツールが担当するのは、右下の
**「取り込みBOX に入れる → 自動で Markdown 化して Obsidian に保存」** の部分です。

---

## 1. 何ができるようになるか

デスクトップにできる **「Obsidian取り込みBOX」** というフォルダに
ファイルを放り込むだけで、10分以内に自動で Obsidian に入ります。

| 入れるファイル | どうなるか |
|---|---|
| `.md` / `.markdown` | 見出しやタグを整えて保存 |
| `.txt` | Markdown に整形して保存 |
| `.docx`（Word） | 本文・見出し・表を Markdown に変換して保存 |
| `.zip` | 中の Markdown ファイルを取り出し、1件ずつ別ノートとして保存 |
| `.pdf` | 文字を取り出して保存（※別途 `pypdf` の導入が必要） |

保存されるノートには、Obsidian で検索・整理しやすいように
先頭へ次のような情報（frontmatter といいます）が自動で付きます。

```markdown
---
title: "定例会議 議事メモ"
created: 2026-08-19
imported: 2026-08-19
source: NotebookLM
source_file: "2026年8月定例_議事メモ.docx"
tags:
  - notebooklm
  - inbox
---

# 定例会議 議事メモ

本日の決定事項は以下の通り。
```

### 安全のための工夫

- **同じ内容は二重に保存されません。**
  本文を照合して、すでに入っているものは自動でスキップします。
  何度エクスポートし直しても、ノートが増殖しません。
- **元のファイルは消えません。**
  処理が終わったファイルは `取り込みBOX/_処理済み/年-月/` に移動して残ります。
- **いきなり書き込みません。**
  セットアップの途中で「何が保存されるか」を先に確認する手順が入っています。

## 2. 準備するもの

- Windows パソコン
- Python 3.8 以上（無料。入っていなければ手順の中で案内します）
- OneDrive の同期が終わっていること
  （エクスプローラーで `OneDrive - ...` の中に
  `ドキュメント > Obsidian > アレクサンドリア図書館` が見えていればOK）

---

## 3. セットアップ手順

### ステップ1：ファイル一式をパソコンに置く

このフォルダ（`obsidian-sync`）を丸ごと、
パソコンの分かりやすい場所にコピーします。

おすすめの置き場所：
```
C:\Users\（自分の名前）\Documents\obsidian-sync
```

> **OneDrive の中には置かないでください。**
> 同期のたびに動いてしまい、動作が不安定になります。

### ステップ2：セットアップを実行する

1. `setup.ps1` を **右クリック**
2. **「PowerShell で実行」** を選ぶ
3. 青い画面が開くので、表示される質問に答える

セットアップは次のことを自動でやります。

| | 内容 |
|---|---|
| 1 | Python が入っているか確認（無ければ入れ方を案内） |
| 2 | OneDrive の中から保管庫を自動で探す |
| 3 | デスクトップに「Obsidian取り込みBOX」を作る |
| 4 | 設定ファイル `config.json` を書き出す |
| 5 | **書き込まずに**動作テスト |
| 6 | 10分おきの自動実行を登録 |

#### 「このシステムではスクリプトの実行が無効になっている」と出たら

会社のPCではよくあるメッセージです。PowerShell に次を貼り付けて Enter を押し、
もう一度 `setup.ps1` を右クリック実行してください。

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

これは「自分のユーザーの範囲でだけ、スクリプトを実行できるようにする」設定です。
パソコン全体の設定は変わりません。

### ステップ3：試してみる

1. メモ帳を開いて適当な文章を書き、
   デスクトップの `Obsidian取り込みBOX` に `テスト.txt` として保存する
2. `run.bat` をダブルクリックする（10分待たずにすぐ実行されます）
3. Obsidian を開いて `Inbox / NotebookLM` を見る

`テスト.md` が出来ていれば成功です。

## 4. 毎日の使い方

### パターンA：会社PCにある文字起こしファイルを入れる

Teams の文字起こし（`.docx`）などを、そのまま取り込みBOX にドラッグするだけです。
Word の見出しや表も、Markdown に変換されます。

### パターンB：NotebookLM のソースをまとめて出す

NotebookLM から手動で書き出したファイルを、取り込みBOX に入れます。

書き出し方はいくつかあります。

1. **Google ドキュメントに書き出す**
   NotebookLM の画面から Google ドキュメントへ出し、
   ブラウザで「ファイル → ダウンロード → Word (.docx)」を選ぶ
2. **画面からコピーして貼り付ける**
   メモ帳に貼って `.txt` で保存する

> **Chrome 拡張機能について**
> 「NotebookLM Sources Exporter」など、ソースを一括で `.md` に落とす拡張機能が
> 公開されています。`.zip` で出てくるので、このツールにそのまま入れられます。
> ただし**会社の情報を第三者が作った拡張機能に読ませることになる**ため、
> 業務資料に使う場合は、事前に会社の情報システム部門に確認してください。

## 5. 設定を変えたいとき

`config.json` をメモ帳で開いて編集します。

| 項目 | 意味 | 例 |
|---|---|---|
| `inbox_dir` | 取り込みBOX の場所 | `C:\\Users\\自分\\Desktop\\Obsidian取り込みBOX` |
| `vault_dir` | Obsidian 保管庫の場所 | `C:\\Users\\自分\\OneDrive - ...\\アレクサンドリア図書館` |
| `subfolder` | 保管庫の中のどこに入れるか | `Inbox/NotebookLM` |
| `tags` | 自動で付けるタグ | `["notebooklm", "inbox"]` |
| `archive_inputs` | 元ファイルを `_処理済み` に移すか | `true` / `false` |
| `filename_template` | ファイル名の形 | `{date}_{title}` |
| `max_title_length` | ファイル名の最大文字数 | `80` |

> `\` は JSON では `\\` と2つ重ねて書く決まりです。ここだけ注意してください。

編集したら `run.bat` で動作を確認してください。

## 6. 困ったとき

| 症状 | 対処 |
|---|---|
| 何も保存されない | `sync.log` を開いて、最後の行のメッセージを確認する |
| 「保管庫が見つかりません」 | OneDrive の同期が終わっているか確認。`config.json` の `vault_dir` を実際のパスに直す |
| 「設定ファイルが見つかりません」 | `setup.ps1` をもう一度実行する |
| PDF が取り込まれない | PowerShell で `pip install pypdf` を実行する |
| 同じノートが増えてしまった | `state.json` を削除すると記録がリセットされます（重複判定もやり直しになります） |
| 自動実行を止めたい | `stop.ps1` を実行する |
| 自動実行を再開したい | `setup.ps1` をもう一度実行する |

### 動いているか確認したい

```powershell
schtasks /Query /TN ObsidianSync_NotebookLM
```

### 書き込まずに動作だけ見たい

```powershell
python sync.py --dry-run
```

## 7. ファイルの説明

| ファイル | 役割 |
|---|---|
| `sync.py` | 本体。変換と保存を行う |
| `setup.ps1` | 初回セットアップ |
| `stop.ps1` | 自動実行の停止 |
| `run.bat` | 手動で1回だけ実行 |
| `config.example.json` | 設定の見本 |
| `config.json` | 実際の設定（セットアップで作られる。**共有しないこと**） |
| `state.json` | 保存済みノートの記録（自動生成） |
| `sync.log` | 実行の記録（自動生成） |

`config.json` `state.json` `sync.log` には個人のフォルダ構成が入るため、
`.gitignore` で GitHub には上がらないようにしてあります。
