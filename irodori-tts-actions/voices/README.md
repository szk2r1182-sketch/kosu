# voices/ — 参照音声の置き場

ここに音声ファイルを置くと、拡張子を除いたファイル名がそのまま「声の名前」になる。

```
voices/narrator.wav   →  voice: narrator
voices/alice_01.wav   →  voice: alice_01
```

ワークフローの `voice` 入力やジョブ定義の `voice:` に、その名前を書けばその声で合成される。
`voice` を空（`null`）にすると参照なしで合成し、話者はシードごとに変わる。

## 対応している形式

- 音声: `.wav` `.flac` `.mp3` `.m4a` `.ogg` `.opus` `.aac` `.webm`
- 事前にエンコードした latent: `.pt` `.pth`
- Speaker Inversion の埋め込み: `.speaker.safetensors`

## 複数ファイルを 1 つの声として使う

同じ話者の短いクリップを複数渡すほうが、長い 1 本を渡すより安定する。
カンマ区切り（ワークフロー入力）か、リスト（ジョブ定義）で指定する。

```yaml
items:
  - id: narration
    voice: [alice_01, alice_02, alice_03]
    text: こんにちは。
```

合計の長さには上限があり、既定ではチェックポイントの推奨値（最大 120 秒程度）で切られる。

## 音源についての注意

- 音声クローンに使う参照音声は、**本人の同意があるもの、または自分に権利があるものだけ**にする。
- このリポジトリが公開設定の場合、ここに置いた音声は誰でもダウンロードできる。
  他人に聞かれて困る音源を置かない。非公開で運用するならリポジトリを private にする。
- 生成した音声を配布・公開するときは、モデル重みのライセンス（Hugging Face のモデルカード）も確認する。
